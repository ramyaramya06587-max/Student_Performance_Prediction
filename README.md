
# Student Performance Prediction

## Project Overview
This project uses Machine Learning to predict students' average academic performance based on demographic information and test preparation details.

## Objective
To analyze student data and build a Machine Learning model that predicts the average score of a student.

## Dataset
The dataset contains 1,000 student records with the following features:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course
- Math Score
- Reading Score
- Writing Score

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Dataset collection
2. Data cleaning and preprocessing
3. Handling missing values
4. Exploratory Data Analysis
5. Data visualization
6. Feature and target selection
7. Training and testing data split
8. Linear Regression model training
9. Prediction and evaluation
10. Saving output files

## Machine Learning Algorithm
Linear Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R2 Score

## Project Files
- Student_Performance.ipynb
- student_performance.csv
- cleaned_student_performance.csv
- student_prediction_results.csv
- README.md
- visualizations/

## Expected Outcome
The project generates predicted average scores and evaluates model performance using standard regression metrics.

## Conclusion
This project demonstrates the application of Machine Learning techniques to student performance prediction using Python.
